# Project memory starter (`kit/fabric/`)

Copy these files into your repository root to give every coding agent (Cursor or any other) a plain-file memory:

- `context/<module>/context.md` — one-page module map (purpose, entry points, data owned, conventions, `related:` links including other repos)
- `specs/<feature>/` — `spec.md`, `plan.md`, `tasks.md`, `findings.md`
- `LESSONS.md` — findings seen twice; promote repeated lessons into `.cursor/rules/`
- `AGENTS.md` — tells the agent to read `context/` first, then search
