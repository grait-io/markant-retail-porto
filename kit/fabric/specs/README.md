# specs/

One folder per feature or ticket: `specs/<feature>/`

- `spec.md` — written by `/speckit.specify` (what and why)
- `plan.md` — written by `/speckit.plan` (how, files, tests, non-goals)
- `tasks.md` — written by `/speckit.tasks` (non-overlapping agent slices)
- `findings.md` — Goldfish review tables and your accept / reject decisions
- `debug.md` — Track C / debug-with-hypotheses: symptom + 3 hypotheses + confirmed/refuted (not only in chat)
